# 文化背景与资料来源 / Cultural Context and Sources

## 中文

本项目是当代数字视觉创作。八卦、阴阳线、二十四山、二十八宿、节气和文字环被重新组织为程序化动态结构，不是对某一历史器物的精确复制。

《易经》拥有符号、文本、哲学、历史和占筮等多层传统。本项目选择“变化、关系、位置与反馈”作为视觉切入点，不提供占卜结论，也不声称代表传统文化的唯一解释。

甲骨材料在这里仅作为中国早期文字与占卜实践的历史背景。商代甲骨占卜与后来形成的六爻或铜钱方法不是同一种程序。

## English

This project is a contemporary digital artwork. Bagua, yin-yang lines, the Twenty-Four Mountains, lunar mansions, solar terms and textual rings are reorganized as a procedural motion system rather than reproduced as a specific historical instrument.

The Changes contains layered symbolic, textual, philosophical, historical and divinatory traditions. This project focuses on change, relationship, position and feedback. It offers no divination result and does not claim to represent the only interpretation of the tradition.

Oracle-bone material appears only as historical context for early Chinese writing and divinatory practice. Shang oracle-bone divination is not the same procedure as later six-line or coin methods.
