# 回 · 手势八卦

[中文](README.md) · [English](README.en.md) · [在线体验](https://huzoukai.github.io/hui-gesture-bagua/)

一个通过单手手势、鼠标和键盘控制的生成式八卦动态体验。

**作者：科技回锅肉**

> 本仓库公开源代码，仅允许个人学习、研究与非商业娱乐使用。未经书面授权，不得用于商业目的。

## 体验

这个项目把手变成界面。使用者不需要控制器，只需要依次完成几个自然动作：

| 动作 | 视觉回应 |
| --- | --- |
| ☝ 伸出食指 | 在指尖位置唤醒阵眼；远近控制亮度 |
| ✊ 握拳 | 从中心逐层展开完整平面阵 |
| 🖐 张开手掌 | 平面结构上下分层，形成三维空间 |
| 🖐 转动掌心 | 控制立体阵的方向和倾角 |
| ↔ 横向挥掌 | 开启或关闭金色旋涡 |
| ✊ 再次握拳 | 从立体状态收回平面 |

项目不包含算卦、六爻生成、问题输入、AI 解读、支付或未来预测功能。

## 手动模式

不启用摄像头也可以完成全部主要动画：

| 操作 | 功能 |
| --- | --- |
| 点击 | 按“阵眼 → 平面 → 立体 → 平面”推进 |
| 移动鼠标 | 控制立体阵方向 |
| 滚轮 | 缩放 |
| **V** | 开关旋涡 |
| **R** | 重置 |
| **M** | 静音 |
| **Esc** | 停止摄像头并切换为手动模式 |

## 为什么制作

八卦在这个项目中不是一个被动观看的装饰图案，而是一套表现变化、关系与位置的动态结构。伸指、握拳、张掌与挥动对应“显现、展开、形成空间、改变方向、回归”的过程。

“回”既是内外嵌套的视觉结构，也是动作发出、视觉回应、注意力重新返回使用者自身的过程。

这是科技回锅肉对传统符号进行的当代数字视觉创作，不是历史罗盘、风水器具或传统仪式的精确复原，也不代表任何文化传统的唯一解释。进一步说明见[文化背景与资料来源](docs/SOURCES.md)。

## 摄像头与隐私

- 摄像头只会在使用者主动点击后开启。
- 视频帧和手部关键点只在浏览器中处理。
- 项目不上传、录制或保存摄像头画面。
- 项目不建立生物识别身份。
- 不使用广告、分析或行为追踪服务。
- 使用者可以随时停止摄像头，或直接选择手动模式。

完整说明见[隐私与摄像头处理](docs/PRIVACY.md)。

## 本地运行

需要 Node.js 20 或更高版本。

~~~bash
npm install
npm run dev
~~~

构建和测试：

~~~bash
npm test
npm run build
~~~

摄像头通常只能在 HTTPS 页面或 localhost 中使用。

## 技术

- [Three.js](https://threejs.org/)：WebGL 三维渲染
- [MediaPipe Hands](https://github.com/google-ai-edge/mediapipe)：浏览器本地手部关键点识别
- [GSAP](https://gsap.com/)：状态动画与缓动
- [Vite](https://vite.dev/)：开发和静态构建

所有太极、文字环、粒子、光晕和冲击波均由代码实时生成，不使用外部商业视觉素材。
