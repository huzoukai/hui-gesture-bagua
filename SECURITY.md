# Security / 安全

Please do not publish camera, privacy or dependency vulnerabilities as a public issue before the maintainer has had a reasonable opportunity to investigate.

请不要在维护者获得合理调查时间之前，通过公开 Issue 披露涉及摄像头、隐私或依赖项的安全漏洞。

Report privately through GitHub Security Advisories for this repository.

请通过本仓库的 GitHub Security Advisories 私下报告。
