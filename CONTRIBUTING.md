# 贡献 / Contributing

## 中文

欢迎提交错误报告、兼容性反馈和非商业功能建议。提交问题时请提供浏览器、设备、操作模式（摄像头或手动）和复现步骤，不要上传包含个人隐私的摄像头录像。

在贡献代码前请先创建 Issue 讨论范围。贡献者保留自己贡献部分的版权；项目方可能在接受较大贡献前要求签署单独的贡献者协议。

提交贡献即表示你确认有权提供相关代码，并同意该贡献在本项目非商业许可证下发布。

## English

Bug reports, compatibility feedback and non-commercial feature proposals are welcome. Include the browser, device, input mode and reproduction steps. Do not upload camera recordings containing personal information.

Please open an issue before preparing a code contribution. Contributors retain copyright in their contributions; the project may require a separate contributor agreement before accepting substantial changes.

By submitting a contribution, you confirm that you have the right to provide it and agree that it may be distributed under the project’s non-commercial license.
